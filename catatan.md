Cara pakai:

Double-click run.bat — otomatis cek FFmpeg, install Flask sekali, buka browser ke http://127.0.0.1:5000
Pilih Video → isi durasi (mis. 30) → Proses Video → hasil muncul di grid (play/pause/download per video + Download Semua ZIP)
Browser relist: tidak perlu, tinggal tutup jendela run.bat
Catatan (ponytail): FFmpeg harus ada di PATH — kalau belum, run.bat menampilkan panduan install langsung.
